# AP-Style Question Banks

This folder is the exclusive content source for the site's **Practice AP** mode.

## Content boundary

- Every unit has a separate Markdown question-bank file produced and reviewed by the question-bank agents.
- Practice AP may use questions only from the appropriate Markdown file in this folder.
- The interactive **Practice Concepts** mode uses the separate question data under `src/content/banks/`. Those questions must never be substituted into Practice AP.
- A filename, section, or question must be explicitly identified as AP-style content before the site imports it into Practice AP.
- If a unit does not yet have an approved AP-style Markdown bank here, its Practice AP option should remain unavailable rather than falling back to another source.

## Naming convention

Use one file per unit:

`AP_CHEM_UNIT_<unit-number>_QUESTION_BANK.md`

Examples:

- `AP_CHEM_UNIT_1_QUESTION_BANK.md`
- `AP_CHEM_UNIT_2_QUESTION_BANK.md`
- `AP_CHEM_UNIT_3_QUESTION_BANK.md`
