# Chemistry verification report

Review date: 2026-09-15. Reviewer: development agent (not a human teacher).

## Sources and method

- [AP Chemistry Course and Exam Description](https://apcentral.collegeboard.org/media/pdf/ap-chemistry-course-and-exam-description.pdf), 2024 framework, Unit 2 pp. 42–56: official scope, topic names, learning objectives, representations, Lewis/formal-charge/resonance/VSEPR expectations, and AP science-practice emphasis.
- [AP Chemistry course overview](https://apstudents.collegeboard.org/courses/ap-chemistry): current nine-unit names, Unit 2 public topic list, and 7–9% weighting.
- [OpenStax Chemistry 2e, Chapter 7](https://openstax.org/books/chemistry-2e/pages/7-introduction): independent cross-check for ionic/metallic/covalent bonding, Lewis structures, formal charge, resonance, VSEPR, and hybridization conventions.
- [OpenStax Chemistry 2e, Section 8.1](https://openstax.org/books/chemistry-2e/pages/8-1-valence-bond-theory): molecular structure and representative bond-length/bond-energy records.

The lesson scope and stored answers were checked against the CED, then definitions and common molecular records were cross-checked with OpenStax. Internal tests independently check counts, IDs, evidence presence, formal-charge sums, referenced structures, coordinate independence, identical-atom permutations, wrong connectivity, electron annotations, and overall charge. The application identifies expanded-octet hybridization as “not assessed” instead of requiring d-hybrid labels.

## Limitations

The records are source-checked by the development agent and are not represented as human-teacher reviewed, College Board approved, or official AP questions. The potential-curve numeric examples use common gas-phase bond-length/dissociation-energy values as instructional reviewed records; actual values can depend on convention and conditions, so displayed tolerances and context remain part of each record. The 3D coordinates are idealized instructional models, not optimized experimental geometries. An educator review is recommended before high-stakes classroom adoption, but no unresolved source gap is knowingly shipped in the active bank.
